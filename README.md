# SimpleTimeSheet


## Requirements for Development
- Node.js (https://nodejs.org/)
- Rust (https://rustup.rs/), (https://v1.tauri.app/v1/guides/getting-started/prerequisites#setting-up-macos)
- Visual Studio Build Tools (for Windows users) (https://visualstudio.microsoft.com/visual-cpp-build-tools/)

## Setup
1. Clone the repository
2. Install dependencies using `npm install`
3. Run the development server using `npm run tauri dev`
